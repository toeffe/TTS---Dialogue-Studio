Streaming TTS

Chat speaks one line. The name before the colon picks the voice for that line.

  1. Double-click start.bat and leave that window open.
  2. In OBS, add a Browser Source with the address below. Check “Control audio via OBS”.
  3. Keep that source in the scene. Slide it off the canvas if the small status line should stay off stream.
  4. In chat, type !tts puck: hello chat.

http://127.0.0.1:8765/listen
