Setup
  1. Double-click start.bat and leave that window open.
  2. Turn on Play through speakers to hear chat on this PC. OBS can stay closed.
  3. To put chat on stream, add a Browser Source with the address below. Check “Control audio via OBS”. Leave that source’s audio monitor off, or each line plays twice.
  4. Keep that source in the scene. Slide it off the canvas if the small status line should stay off stream.
  5. In chat, type !tts puck: hello chat. A cue alone needs no voice: !tts (bark).
  6. Chat plays a sound only after you approve it below. A MyInstants id looks like caching-49444. Dialogue Studio adds a sound when you use it.
